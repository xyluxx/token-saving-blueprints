# Banner provenance

Original document-cover composition using Geist typography, informed by the public [Geist Book reference](https://vercel.com/geist/book). No Vercel logo or product screenshot is reproduced. The raster banner depicts this repository’s two blueprint modes, not a software interface. Scenario figures are calculated examples, not observed results; see the README and examples/api-cost-scenario.json.

Geist font source: https://github.com/google/fonts/tree/main/ofl/geist (SIL Open Font License). Font software is not bundled in this repository.
